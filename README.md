### 🧭 How I work

- **Understand the business first** — I start from the real workflow (who collects, who approves, who pays) before designing tables or screens.
- **Own it end to end** — schema, API, UI, permissions and deployment.
- **Ship safely** — role-based access, input validation, secrets out of the repo, and CI that blocks broken builds.
- **Honest metrics** — I describe what a system does, not invented percentages.
